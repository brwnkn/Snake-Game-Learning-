# Snake Game

A simple browser-based Snake game built with HTML, CSS, and JavaScript.

This is a snake game that was built with the help of starter code from Babita at https://www.c-sharpcorner.com/article/classic-snake-game-with-simple-html-css-and-javascript/. This project is meant to help me practice the html, css, and js skills I learnt throughout winter 2025.


## Features
- Grid-based movement
- Food generation
- Collision detection
- Score tracking

## How to Play
1. Open `snakegame.html` in a browser
2. Use arrow keys to control the snake
